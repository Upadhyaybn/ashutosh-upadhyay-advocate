# Ashutosh Upadhyay Advocate Website

Professional informational website and web application for Advocate Ashutosh Upadhyay, practicing in Siddharthnagar, Uttar Pradesh, India.

## Preferred Production Domain

`ashutoshupadhyayadvocate.in`

> Domain availability and ownership will be verified before registration.

## Project Status

Under active development.

## Architecture

The application follows a modular monolithic architecture.

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

### Backend

- Java 25
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- Jakarta Bean Validation
- REST APIs
- OpenAPI / Swagger
- Maven

### Database

- PostgreSQL
- Flyway

### Testing

Backend:

- JUnit 5
- Mockito
- Spring Boot Test
- MockMvc
- Testcontainers

Frontend:

- Vitest
- React Testing Library
- Playwright

### Infrastructure

- Docker
- GitHub Actions
- Cloudflare
- Custom Domain
- HTTPS

## Security

Passwords, database credentials, API keys, cloud credentials,
certificates and production secrets must never be committed to
this repository.

## Compliance

All professional details, qualifications, practice areas,
memberships and other claims must be confirmed by the client
before publication.

The website will remain professional, factual and informational
and will avoid unsupported promotional claims.
